# Personal Mini-Toolkit

## What This Toolkit Does

The Personal Mini-Toolkit is a Python program that provides four useful tools in one simple menu. The tools are a Simple Calculator, To-Do List, Number Guessing Game, and Name Formatter. The calculator performs basic arithmetic operations. The To-Do List allows users to add, view, and remove tasks. The Number Guessing Game allows the user to keep guessing until the correct number is found. The Name Formatter cleans and formats a user's name in a friendly way.

## How to Run

1. Open PowerShell or the VS Code terminal.
2. Navigate to the `plp-python-week8` folder.
3. Run the following command:

```text
python toolkit.py
```

4. Choose a number from the menu and follow the instructions.
